**The fix.** `paired_infonce_with_memory` now removes each population's common direction before the
similarity: current rows and the detached key queue are centred independently, within each modality.
The shared-offset variant was tried first and rejected on evidence — a frozen queue drifts away from
the live states, so imposing the batch's offset on it reached the criterion at step 200 and then
diverged to 7.62 and full collapse. Batches below `min_negatives` borrow the estimate from the queue,
because centring B=1 by its own mean yields the zero vector and B=2 an antipodal pair, and real D1
batches are B=1–3.

**The graded metric was deliberately left alone.** Centring changes the value of the very number
G2.6 thresholds at ≤ 0.10, so `biology_contrastive` keeps its historical definition — uncentred,
queue included — and the centred value is reported beside it as `biology_contrastive_centred`. A fix
to the optimisation must not be able to pass as a relaxed criterion. All numbers quoted above are the
**raw uncentred** metric.

**Where it now stands, and the honest bad news.** Running the *actual* gate
(`_overfit_programme_free_contrastive` + `_require_programme_free_overfit`, unmodified) on seeds
42/43/44:

| 43 | — | — | — | **2.4355** | — | FAIL |

The gate now *solves its own objective* — total loss 6.70 → 0.021, a 99.7% reduction, against 2.7726
before the fix. But the raw graded metric sits at ~2.6, still near chance, where a contrastive-only
centred run reaches 0.0101 at the same step count. So the centring fix works and something among the
three remaining `programme_free` terms — `biology_full_consistency` 1.0, `decorrelation` 0.04,
`variance` 0.01 — preserves the batch-common direction that the centred loss is by construction
indifferent to. An ablation of the real gate over those weights is running.

Prime suspect on prior evidence: `biology_full_consistency` = `1 − cos(z_bio_full, z_bio_wsi.detach())`
at weight 1.0, equal to the contrastive term. It is trivially satisfied when both states sit on a
shared direction, so it *rewards* the common component — and `diag_c` already measured that adding it
to a non-collapsing in-batch run made that run collapse by step 100. Its declared purpose is only to
give the exported `full_biology` state a gradient path.

### In plain terms

The model was destroying its own ability to tell patients apart because everything it produced was
dominated by one big "average patient" direction. Subtracting that average before comparing patients
fixes it outright: the model goes from indistinguishable to identifying all sixteen patients
correctly, and stays there for three thousand steps.

But the gate is still red, and for an instructive reason. Subtracting the average makes the model
*learn* properly, but it also means the objective stops caring how big that average component is. The
model happily learns to identify patients in the leftover space while keeping the big shared
component intact — and the gate's number is computed without the subtraction, so it still sees the
shared component drowning everything. Something else in the objective is actively keeping that
component large, and the run to find out which is in flight.

### Meaning for the claim

The rank-1 collapse is fixed and that fix is solid and reproducible. The gate is not yet passed. The
threshold has not been touched and should not be: a contrastive-only centred run reaching 0.0101 on
the *same raw metric* is proof by construction that ≤ 0.10 is attainable on this cohort, this batch
and this encoder. Anything that still fails is a defect in the remaining terms, not in the criterion.
